# 🚀 地块搜索功能快速体验指南

5分钟快速体验地球热点搜索功能！

---

## 第一步：启动应用 (1分钟)

```bash
# 1. 进入项目目录
cd solarSystem/solarSystem

# 2. 启动服务（如果还没启动）
npm start
```

等待看到以下提示：
```
✅ 前端服务运行在: http://localhost:8095
✅ 后端API运行在: http://localhost:3000
```

---

## 第二步：登录系统 (1分钟)

1. 打开浏览器访问：http://localhost:8095/auth.html
2. 如果已有账号，直接登录
3. 如果没有账号：
   - 点击"立即注册"
   - 填写基本信息（用户名、邮箱）
   - 获取邮箱验证码（开发模式下会显示在控制台）
   - 完成注册并登录

---

## 第三步：开始搜索 (3分钟)

登录成功后会自动跳转到主页，你会看到：

### 1️⃣ 找到搜索框
- 位置：页面左上角
- 外观：黑色半透明背景，带有紫色渐变按钮

### 2️⃣ 尝试搜索北极点
```
在搜索框输入：0
点击"定位"按钮
```

**你会看到**：
- 相机平滑飞向北极点（2秒动画）
- 显示地块信息面板
- 显示坐标：约 (90°N, 0°E)
- 提示："已定位到地块 #0"

### 3️⃣ 探索其他有趣的位置

**中纬度地区**：
```
输入：50000000
按 Enter 键
```

**南半球**：
```
输入：100000000
点击"定位"
```

**赤道附近**：
```
输入：63500000
点击"定位"
```

### 4️⃣ 测试输入验证

**试试无效输入**：
```
输入：999999999  （超出范围）
```
👉 会看到错误提示："地块编号超出范围"

```
输入：-100  （负数）
```
👉 会看到错误提示："请输入有效的地块编号"

## 🎯 核心功能演示

### 功能1: 点击与搜索结合使用

1. **搜索到一个位置**：
   ```
   输入：1000000
   点击定位
   ```

2. **点击附近的地球表面**：
   - 会显示点击位置的地块信息
   - 可以看到编号接近 1000000

3. **再搜索另一个位置**：
   ```
   输入：5000000
   点击定位
   ```

### 功能2: 快速连续搜索

依次快速输入并搜索：
```
100 → Enter
500 → Enter
1000 → Enter
```

观察相机如何平滑地在不同地块间移动。

### 功能3: 查看地块详情

搜索到任意地块后：
1. 信息面板会自动弹出
2. 显示内容包括：
   - 地块编号
   - 中心坐标（经度、纬度）
   - 纬度范围
   - 经度范围
3. 可以点击"复制坐标"
4. 可以点击"保存热点"收藏

## 🎮 互动提示

### 提示1: 使用键盘快捷键
- **Enter键**：快速搜索（不用点鼠标）
- **Tab键**：切换到定位按钮

### 提示2: 理解编号规则
```
编号 0        → 北极点
编号 1-10000  → 北极圈内
编号 10001-50000000 → 北半球
编号 50000001-75000000 → 赤道附近
编号 75000001-120000000 → 南半球
编号 120000001-126999999 → 南极圈附近
```

### 提示3: 找到特定城市
虽然目前不支持直接搜索城市名，但你可以：
1. 点击地球表面的城市位置
2. 查看弹出的地块编号
3. 记下编号，下次直接搜索

## 🐛 常见问题

### Q: 搜索后相机不动？
**A**: 检查浏览器控制台是否有错误，确保：
- 已登录系统
- 地球模型已加载完成
- 输入的是有效数字

### Q: 提示消失太快？
**A**: 在 `EarthHotspots.js` 中修改：
```javascript
setTimeout(() => {
  resultDiv.style.display = 'none';
}, 5000);  // 改为5秒
```

### Q: 想要更平滑的动画？
**A**: 修改缓动函数：
```javascript
.easing(TWEEN.Easing.Cubic.InOut)  // 更平滑
// 或
.easing(TWEEN.Easing.Elastic.Out)  // 弹性效果
```
